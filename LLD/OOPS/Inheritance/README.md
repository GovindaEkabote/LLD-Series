
# Inheritance and Its Types in Java

## Aim
To study and implement different types of inheritance
in Java using classes and interfaces.

## Introduction
Inheritance is an important feature of Object-Oriented
Programming (OOP).

It allows one class to acquire the properties and methods
of another class.

## Types of Inheritance

1. Single Inheritance
2. Multilevel Inheritance
3. Hierarchical Inheritance
4. Multiple Inheritance
5. Hybrid Inheritance

## Keywords Used

- extends
- implements
- interface
- class

## Program Description

This program demonstrates all five commonly discussed
types of inheritance in Java.

1. Single Inheritance:
   Dog inherits from Animal.

2. Multilevel Inheritance:
   Puppy inherits from Dog, and Dog inherits from Animal.

3. Hierarchical Inheritance:
   Dog and Cat inherit from Animal.

4. Multiple Inheritance:
   Child implements Father and Mother interfaces.

5. Hybrid Inheritance:
   Result extends Student and implements Sports interface.

## Output

1. Single Inheritance
Animal is eating
Dog is barking

2. Multilevel Inheritance
Animal is eating
Dog is barking
Puppy is weeping

3. Hierarchical Inheritance
Animal is eating
Cat is meowing

4. Multiple Inheritance
Child inherits father's qualities
Child inherits mother's qualities

5. Hybrid Inheritance
Student is studying
Student is playing sports

## How to Run

1. Save the file as Inheritance.java.
2. Open the terminal in the project folder.
3. Compile the program:

   javac Inheritance.java

4. Execute the program:

   java Inheritance

## Advantages of Inheritance

- Code reusability
- Reduces code duplication
- Easy maintenance
- Supports method overriding
- Improves code organization

## Conclusion

Inheritance allows a class to reuse the properties
and methods of another class.

Java supports single, multilevel and hierarchical
inheritance through classes. Multiple and hybrid
inheritance can be achieved using interfaces.
